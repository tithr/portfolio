# portfólio

Site estático para GitHub Pages.

## publicar

1. Crie um repositório no GitHub e envie estes arquivos para ele.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`; salve.
5. O GitHub exibirá o endereço público do site em alguns minutos.

Antes de publicar, edite `index.html` para trocar:

- os links dos projetos e do GitHub.
